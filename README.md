# Capricornio Studio 83

Proyecto de página web para la asignatura **Diseño y Desarrollo de Software**.

- **Sitio publicado:** https://bustosc1783-b.github.io/mi-pagina/
- **Repositorio:** https://github.com/bustosc1783-b/mi-pagina

## Contenido

Sitio de una página con las secciones Estudio, Servicios, Universos visuales, Relato, Proceso y Contacto. Incluye una galería y el relato ilustrado *Martes hoy, martes mañana*.

## Tecnologías

- HTML5 semántico.
- CSS responsivo y Bootstrap 5 guardado localmente.
- Imágenes en WebP y recursos originales conservados.
- JavaScript para menú móvil, ampliación de imágenes y carrusel (fuera del alcance de la evaluación de JavaScript).

## Comprobación

Desde la raíz del repositorio:

```bash
python3 -m unittest discover -s tests -v
```

La prueba verifica la lista de pasos, un ajuste para tablets estrechas, los recursos locales y el peso de las imágenes.
